# Reference Video Analysis — implemented site language

Source: `1000262620.mp4`, approximately 60 seconds. Only the website inside the browser rectangle was treated as reference. Reel labels, the purple presentation background, “3D Agency Website”, “FOR MY U.S. CLIENT”, and `antimatterai.com` were excluded.

## Home sequence

- Hero: compact navigation, near-black canvas, huge ghost wordmark, centered particle object, oversized editorial headline, supporting copy/CTA and compact qualitative labels.
- Services: dark pinned storytelling; particle sculpture on one side, one dominant active card and narrow adjacent cards, scroll-controlled sequence.
- Work: compact list rows paired with a large preview panel.
- Proof/testimonial composition: one large card paired with two smaller cards. In Machos Bey this maps to real pillar content, not invented testimonials.
- CTA/footer: wide rounded CTA with animated light field, then compact footer on the same visual system.

## Company/About sequence in the second half

- Large black hero with restrained negative space, small manifesto/support copy and a dominant editorial statement.
- Large story/manifesto section with an abstract dotted visual instead of stock photography.
- Three-card team-like composition. Because the source content contains no team names/photos, it maps to Vision / Mission / Values.
- Large horizontal principle/value rows with thin separators.
- Wide final CTA with a large abstract visual on the opposite side. The original astronaut was not copied; Machos Bey uses its particle/brand language instead.

## Internal-page implementation

- `/about` follows the Company-page sequence most closely.
- `/business-setup` and `/digital-services` reuse the reference service-story mechanism with real source services.
- `/careers` keeps the dark editorial hero, a restrained three-card benefits composition, and a real application form.
- `/contact` uses the same typography, spacing and dark/light rhythm while prioritizing a real form and only verified contact fields.

## Brand translation

- Purple/violet role replaced with Machos Bey blue.
- Metallic logo mark is used in navigation/footer.
- Sharp slash + elliptical sweep geometry derived from the supplied logo appears sparingly as a repeated identity motif.
- Dark sections use charcoal-blue rather than pure black; light sections use a cool blue-gray rather than pure white.
- Section changes use direct cuts, as approved after testing gradient transitions.
